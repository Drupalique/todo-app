# Todo App

A simple todo app built with React and Vite.

## Features

- Add tasks by typing and pressing Enter or clicking Add
- Mark tasks complete with a checkbox
- Delete tasks with the ✕ button
- Live count of remaining tasks

## New sections

- Adding frog form.

## Getting Started

```bash
npm install
npm run dev
```

Then open http://localhost:5173 in your browser.

## Build

```bash
npm run build
```

Produces a static site in the `dist/` folder.
